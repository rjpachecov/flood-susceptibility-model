# Flood Susceptibility Mapping Using WoE and AHP

## Overview
This repository contains a Python-based workflow for flood susceptibility mapping using geospatial data and statistical and multi-criteria methods.

## Objectives

- Prepare and analyze flood-conditioning factors.
- Implement the Weights of Evidence (WoE) method.
- Develop a flood susceptibility index.
- Explore the application of the Analytical Hierarchy Process (AHP).
- Evaluate and visualize the spatial distribution of flood susceptibility.

## Study Area

The workflow is designed for watershed-scale applications. In particular, we apply this code to the San Jorge basin in Colombia.

## Repository Structure

- notebooks/: Jupyter Notebooks documenting the analysis.
- images/: Figures and diagrams used in the documentation.
- src/: Reusable Python functions.

## Requirements

Python and the geospatial libraries listed in requirements.txt.

## Data Availability

The workflow uses geomorphology, land cover and base cartography shapefiles from the "Plan de Ordenación y Manejo de la Cuenca Hidrográfica del Río Bajo San Jorge - NSS", developed through collaboration among CVS, CORPOMOJANA, CARSUCRE, CSB, CORANTIOQUIA, and Fondo Adaptación - Ministerio de Hacienda y Crédito Público of Colombia.

## Reproducibility

Run the notebook in order after installing the required libraries and configuring the input data paths.
